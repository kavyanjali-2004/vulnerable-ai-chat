# Vulnerable AI Chat Application

This application demonstrates common OWASP LLM vulnerabilities including Prompt Injection (LLM01) and Sensitive Information Disclosure (LLM06).

## Setup Instructions

1. Ensure Ollama is running with `llama3`.
2. Install dependencies: `pip install -r requirements.txt`
3. Run application: `python app.py`
4. Open browser at `http://localhost:5000`
